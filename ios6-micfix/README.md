# iPhone 4S Bottom Mic Redirect

Target: iPhone 4S (iPhone4,1), iOS 6.x, Cydia Substrate.

The tweak hooks the legacy AudioSession API and replaces modes commonly associated with the upper microphone (video recording / voice chat / game chat) with the default mode, which on iPhone 4/4S selects the bottom microphone.

Package ID: com.raulkong89.bottommicredirect
